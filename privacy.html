개인정보처리방침

책공장 (BookFactory) · 시행일 2026년 9월 29일

책공장(이하 「앱」)은 한 사람이 자기 기기에서 쓰려고 만든 개인용 앱입니다. 이 글은 앱이 어떤 정보를 어디에 두고 어떻게 쓰는지 적은 것입니다.

1. 한 줄 요약

앱에는 서버가 없습니다. 앱이 다루는 자료는 사용자의 기기와 사용자 본인의 구글 드라이브에만 있고, 만든 사람을 포함해 누구에게도 보내지 않습니다. 광고·분석 도구도 넣지 않았습니다.

2. 앱이 다루는 정보

  • 읽기 기록 — 읽던 자리, 형광펜, 책갈피, 메모, 책에 단 태그
  • 글서랍 — 사용자가 앱 안에서 적은 글과 그 이력
  • 기기 이름 — 어느 기기에서 고쳤는지 표시하려고 씁니다
  • 진단 로그 — 사용자가 켰을 때만, 앱이 겪은 오류와 동작 기록

이름·전화번호·위치·연락처 같은 정보는 모으지 않습니다. 사용자가 여는 책과 문서의 내용은 기기 안에서만 읽고 어디로도 보내지 않습니다.

3. 구글 계정과 구글 드라이브 권한

구글 로그인은 사용자가 동기화를 켤 때만 합니다. 앱이 청하는 권한과 그 쓰임은 다음과 같습니다.

권한쓰임
drive.appdata
앱 전용 폴더		 위 2의 읽기 기록과 글서랍을 사용자 본인의 기기끼리 맞추려고, 사용자 드라이브의 앱 전용 숨은 폴더에 담고 읽습니다. 이 폴더는 이 앱 말고는 보지 못하며, 앱도 이 폴더 밖의 파일은 볼 수 없습니다.
drive.file
앱이 만든 파일 (안드로이드만)		 사용자가 켰을 때 진단 로그를 사용자 드라이브에 올립니다. 앱이 직접 만든 파일과 폴더만 다룰 수 있습니다.
drive.readonly
드라이브 읽기 (안드로이드만)		 사용자가 「드라이브를 책장으로 쓰기」를 켰을 때, 사용자 드라이브에 있는 책과 문서를 읽어서 화면에 보여 주는 데만 씁니다. 파일을 고치거나 지우거나 옮기지 않으며, 읽은 내용을 어디로도 보내지 않습니다.

로그인하며 받은 토큰은 그 기기 안에만 두고, 드라이브에 접근하는 데만 씁니다.

4. 구글 API 서비스 사용자 데이터 정책

이 앱이 구글 API 로 받은 정보를 쓰고 다른 앱으로 옮기는 일은 Google API Services User Data Policy를 따르며, 그 정책의 Limited Use(제한적 사용) 요건을 지킵니다. 구글 사용자 데이터를 광고에 쓰거나, 팔거나, 남에게 넘기지 않으며, 사람이 읽지도 않습니다.

5. 남에게 주는 정보

없습니다. 자료는 사용자 기기와 사용자 본인의 구글 드라이브 사이에서만 오갑니다.

6. 보관과 지우기

  • 기기 안의 자료는 앱을 지우면 함께 지워집니다.
  • 동기화를 끄면 앱은 드라이브에 더 접근하지 않습니다. 드라이브의 앱 전용 폴더에 남은 자료는 구글 드라이브 설정의 「앱 관리」에서 이 앱의 숨은 데이터를 삭제해 지울 수 있습니다.
  • 앱에 준 권한은 언제든 구글 계정 → 서드 파티 연결에서 거둘 수 있습니다.
